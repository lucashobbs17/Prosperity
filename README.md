# ProsperityTeam

Shared trading challenge workspace.

## Structure
- `traders/round0` : round 0 trader files
- `traders/round1` : round 1 trader files
- `backtesting` : local backtesting tools
- `analysis` : plotting and research scripts
- `data_notes` : notes, writeups, and observations
